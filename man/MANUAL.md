## 🧭 1. ภาพรวมและปรัชญาของระบบ (Overview & Core Philosophy)

**`zbash`** คือตัวแปลคำสั่งและเชลล์อินเตอร์แอคทีฟยุคใหม่ (Command Language Interpreter & Interactive Shell) ที่พัฒนาขึ้นด้วยภาษา Cleanroom ISO C11 ร่วมกับชุดคำสั่งสถาปัตยกรรม Apple Silicon ARM64 NEON เพื่อมุ่งเน้นความเป็นเลิศ 3 ประการ:

1. **Hardware-Accelerated Throughput (35+ GB/s):**  
   ใช้ตัวแยกคำสั่งระดับเวกเตอร์ฮาร์ดแวร์ (ARM64 SIMD Vector Lexer) สแกนโทเค็นด้วยอัตราความเร็วสูงสุดโดยไม่สร้างขยะหน่วยความจำ (Zero-Allocation Parsing)
2. **First-Class Interactive Ergonomics:**  
   ออกแบบประสบการณ์การใช้งานบนหน้าจอเทอร์มินัลให้สวยงาม ทรงพลัง และสะดวกสบายสูงสุดในตัว โดยไม่ต้องพึ่งพาเฟรมเวิร์กหรือสคริปต์ภายนอก
3. **Strict Standards Conformance (POSIX.1-2017):**  
   รักษาความเข้ากันได้ของโครงสร้างไวยากรณ์ คำสั่งภายใน และระบบไปป์ไลน์ตามมาตรฐานสากลอย่างสมบูรณ์แบบ 100%

## 🚀 2. การเรียกใช้งานและไฟล์ตั้งค่า (Invocation & Configuration Files)

### 📌 รูปแบบคำสั่ง (Command-Line Usage)
```sh
zbash [-c command_string] [-i] [-s] [--help] [--version] [file [arguments...]]
```

| ตัวเลือก (Option) | คำอธิบายการทำงาน |
|:---|:---|
| **`-c string`** | อ่านและประมวลผลคำสั่งจากสตริงที่ระบุ แล้วคืนค่าสถานะทันที |
| **`-i`** | บังคับให้เชลล์ทำงานในโหมดโต้ตอบ (Interactive Mode) แม้ไม่ได้ต่อกับ TTY |
| **`-s`** | อ่านคำสั่งจาก Standard Input โดยเก็บอาร์กิวเมนต์ที่เหลือไว้ในพารามิเตอร์ตำแหน่ง |
| **`--help`** | แสดงสรุปตัวเลือกการเรียกใช้งานและออกจากโปรแกรม |
| **`--version`** | แสดงหมายเลขเวอร์ชัน สถาปัตยกรรมชิป และข้อมูลลิขสิทธิ์ |

### 📂 ไฟล์ตั้งค่าเริ่มต้นของระบบ (Startup Files Sequence)
เมื่อเริ่มต้นทำงาน `zbash` จะอ่านไฟล์ตั้งค่าตามลำดับดังต่อไปนี้:

1. **`/etc/zprofile`**  
   ไฟล์ตั้งค่าส่วนกลางของระบบ อ่านเฉพาะเมื่อรันเป็น Login Shell
2. **`~/.zprofile`**  
   ไฟล์ตั้งค่าส่วนตัวของผู้ใช้ อ่านเมื่อรันเป็น Login Shell
3. **`~/.zbashrc`**  
   ไฟล์ตั้งค่าหลักสำหรับ Interactive Shell เป็นตำแหน่งหลักสำหรับกำหนด Alias, Environment Variables, และ Hook Functions
4. **`~/.zbash_history`**  
   ไฟล์เก็บบันทึกประวัติคำสั่งถาวร ซึ่งจะได้รับการอัปเดตแบบเรียลไทม์ข้ามทุกหน้าต่างเทอร์มินัล

## 🎨 3. หน้าจอโต้ตอบอัจฉริยะ (The Interactive Environment)

`zbash` มาพร้อมกับระบบแสดงผลสองบรรทัด (Two-Line Dynamic Prompt) ที่คำนวณและเรนเดอร์ในหน่วยความจำโดยตรง:

```text
╭─ zbash in ~/projects/engine on git:(main)*
╰─❯ ls -la
```

### 1) แถบบริบท (Top Context Bar)
* **ชื่อเชลล์ (`zbash`):** แสดงตัวตนของเชลล์ด้วยสี Neon Electric Aqua
* **พาธไดเรกทอรีอัจฉริยะ:** ย่อเส้นทางอัตโนมัติ โดยแทนที่ Home Directory ด้วย `~` และย่อพาธยาวเกินกำหนดด้วยจุดไข่ปลา `…/` (เช่น `~…/zero-tools/zbash`)
* **การตรวจจับกิ่งซอร์สโค้ด (Zero-Subprocess Git Inspection):**  
  ตรวจสอบสถานะของ Git Repository จากไฟล์ `.git/HEAD` และ `.git/index` ภายในหน่วยความจำ C โดยตรง **ไม่สร้างโปรเซสลูกภายนอก** ทำให้ Prompt เรนเดอร์ได้ในเวลาไม่ถึงเสี้ยววินาที (พร้อมเครื่องหมาย `*` สีส้มเมื่อมีไฟล์ที่ยังไม่ได้คอมมิต)

### 2) แถบรับคำสั่งและสถานะ (Bottom Action Bar)
* **สัญลักษณ์ลูกศร (`╰─❯`):**  
  * **สีเขียวนีออน (Neon Emerald):** เมื่อคำสั่งก่อนหน้าทำงานสำเร็จ (`$? == 0`)
  * **สีแดงทับทิม (Ruby Red):** เมื่อคำสั่งก่อนหน้าเกิดข้อผิดพลาด พร้อมแสดงรหัส Error ทันที เช่น `[127] ╰─❯ `
* **ระบบจับเวลาคำสั่ง (`ZBASH_CMD_DURATION`):**  
  คำนวณระยะเวลาจริงของคำสั่งล่าสุดในระดับมิลลิวินาที และส่งออกสู่ตัวแปรสภาพแวดล้อมให้สคริปต์นำไปใช้งานต่อได้

## 🪝 4. ระบบสกัดกั้นเหตุการณ์วงจรชีวิต (Lifecycle Event Hooks)

`zbash` รองรับฟังก์ชันตรวจจับเหตุการณ์สำคัญในเชลล์ (Native Event Hooks) ช่วยให้ผู้ใช้เขียนสคริปต์ปรับแต่งการทำงานได้ตามต้องการ:

### 1) `precmd` (ก่อนแสดง Prompt)
ถูกเรียกทำงานอัตโนมัติทันทีก่อนที่ `zbash` จะวาด Prompt ในแต่ละรอบ เหมาะสำหรับอัปเดตชื่อหน้าต่างเทอร์มินัล:
```sh
precmd() {
    # ส่งรหัส ANSI อัปเดต Title Bar ของ Terminal
    printf "\033]0;zbash: %s\007" "$PWD"
}
```

### 2) `preexec` (ก่อนเริ่มรันคำสั่ง)
ถูกเรียกทำงานทันทีหลังจากผู้ใช้กด Enter และก่อนที่คำสั่งจะเริ่มทำงาน โดยรับข้อความคำสั่งเต็มผ่านอาร์กิวเมนต์ตัวแรก (`$1`):
```sh
preexec() {
    echo "[กำลังประมวลผล: $1]"
}
```

### 3) `chpwd` (เมื่อเปลี่ยนไดเรกทอรีทำงาน)
ถูกเรียกทำงานอัตโนมัติทุกครั้งที่มีการเปลี่ยนไดเรกทอรีผ่านคำสั่ง `cd`, `pushd`, หรือ `popd`:
```sh
chpwd() {
    # แสดงรายชื่อไฟล์ทันทีที่เปลี่ยนโฟลเดอร์
    ls -F
}
```

## 📂 5. สแต็กไดเรกทอรีและการนำทาง (Directory Stack Navigation)

นอกจากคำสั่ง `cd` มาตรฐานแล้ว `zbash` ยังมีระบบจดจำประวัติไดเรกทอรีแบบ Stack ในตัว:

| คำสั่ง (Command) | การทำงาน |
|:---|:---|
| **`pushd [dir]`** | บันทึกไดเรกทอรีปัจจุบันลงใน Stack แล้วเปลี่ยนไปที่ `dir` |
| **`pushd +N` / `-N`** | หมุนสลับไดเรกทอรีใน Stack ตามลำดับดัชนี |
| **`popd`** | ดึงไดเรกทอรีบนสุดออกจาก Stack และเปลี่ยนตำแหน่งกลับไป |
| **`popd +N` / `-N`** | ลบไดเรกทอรีลำดับที่กำหนดออกจาก Stack |
| **`dirs -v`** | แสดงรายการไดเรกทอรีทั้งหมดใน Stack พร้อมหมายเลขกำกับ |
| **`dirs -c`** | ล้างรายการทั้งหมดใน Directory Stack |
| **`cd -`** | สลับกลับไปยังไดเรกทอรีทำงานก่อนหน้า (`$OLDPWD`) |

ตัวแปรอาร์เรย์ **`${DIRSTACK[@]}`** จะเก็บรายการไดเรกทอรีทั้งหมด โดยที่ `${DIRSTACK[0]}` คือไดเรกทอรีปัจจุบันเสมอ

## 🔄 6. ระบบบันทึกประวัติคำสั่งหลายเซสชัน (Shared History Engine)

* **Multi-Session Instant Synchronization:**  
  คำสั่งที่พิมพ์จะได้รับการบันทึกลงในไฟล์ `~/.zbash_history` ทันทีที่ทำงานเสร็จสิ้น โดยไม่ต้องรอให้ผู้ใช้ปิดหน้าต่างเชลล์ ทำให้ประวัติคำสั่งซิงค์ข้ามทุกแท็บอย่างราบรื่น
* **Automated Deduplication (`H_SETUNIQUE`):**  
  ระบบจะกรองคำสั่งซ้ำซ้อนติดต่อกันไม่ให้บันทึกซ้ำโดยอัตโนมัติ
* **ตัวแปรควบคุมประวัติคำสั่ง:**
  * **`HISTSIZE`**: กำหนดจำนวนคำสั่งสูงสุดที่จะบันทึกไว้ในหน่วยความจำ (ค่าเริ่มต้น: 2000)
  * **`HISTFILE`**: กำหนดตำแหน่งไฟล์บันทึกประวัติคำสั่ง
  * **`HISTCONTROL`**: ควบคุมการข้ามคำสั่ง เช่น `ignoredups` (ไม่บันทึกคำสั่งซ้ำ) หรือ `ignorespace` (ไม่บันทึกคำสั่งที่ขึ้นต้นด้วยช่องว่าง)
  * **`HISTIGNORE`**: กำหนดแพทเทิร์นของคำสั่งที่ไม่ต้องการให้บันทึก

## ⌨️ 7. โหมดการพิมพ์และปุ่มลัด (Line Editing & Keybindings)

`zbash` ใช้ตัวจัดการบรรทัดคำสั่งแบบเนทีฟ รองรับทั้งโหมด Emacs และ Vi:

### ปุ่มลัดโหมด Emacs (ค่าเริ่มต้น)
* **`Ctrl-A` / `Ctrl-E`**: เลื่อนเคอร์เซอร์ไปหน้าสุด / ท้ายสุดของบรรทัด
* **`Alt-F` / `Alt-B`**: กระโดดข้ามทีละคำไปข้างหน้า / ข้างหลัง
* **`Ctrl-K`**: ตัดข้อความตั้งแต่เคอร์เซอร์ไปจนสุดบรรทัด
* **`Ctrl-U`**: ลบข้อความทั้งบรรทัด
* **`Ctrl-W`**: ลบหนึ่งคำก่อนหน้าเคอร์เซอร์
* **`Ctrl-R`**: ค้นหาประวัติคำสั่งย้อนหลังแบบอินเตอร์แอคทีฟ (Incremental Search)
* **`Tab` (`^I`)**: เติมคำสั่งและชื่อไฟล์อัตโนมัติ (Context-Aware Completion)

### การสลับโหมด
* เปิดโหมด Vi: `set -o vi`
* เปิดโหมด Emacs: `set -o emacs`

## 🔢 8. ตัวแปรและโครงสร้างข้อมูล (Variables & Data Structures)

### 1) อาร์เรย์แบบดัชนีตัวเลข (Indexed Arrays)
เริ่มต้นนับสมาชิกตัวแรกที่ดัชนี **0 (`${arr[0]}`)** ตามมาตรฐานสากล:
```sh
servers=(web-01 app-02 db-03)
echo "${servers[0]}"      # ผลลัพธ์: web-01
echo "${servers[@]}"      # พิมพ์สมาชิกทั้งหมด
echo "${#servers[@]}"     # จำนวนสมาชิก (3)
```

### 2) อาร์เรย์แบบตารางจับคู่ค่า (Associative Arrays / Hash Maps)
ประกาศสร้างตาราง Key-Value ด้วยคำสั่ง `declare -A` หรือ `typeset -A`:
```sh
declare -A config
config[host]="127.0.0.1"
config[port]="8080"
config[env]="production"

echo "Connecting to ${config[host]}:${config[port]}..."
```

### 3) ตัวแปรพิเศษของระบบ (Special Parameters)
* **`$?`**: รหัสผลลัพธ์ของคำสั่งล่าสุด (0 = สำเร็จ)
* **`$#`**: จำนวนอาร์กิวเมนต์ที่ส่งเข้ามา
* **`$$`**: Process ID (PID) ของเชลล์ปัจจุบัน
* **`$!`**: Process ID ของงานเบื้องหลังล่าสุด
* **`$0`**: ชื่อไฟล์สคริปต์หรือโปรแกรมเชลล์ที่กำลังทำงาน
* **`$@` / `$*`**: รายการอาร์กิวเมนต์ทั้งหมด (`"$@"` จะรักษาการแยกคำตามช่องว่างอย่างถูกต้อง)

## 📖 9. คู่มือคำสั่งภายในระบบ (Builtin Commands Reference)

`zbash` มีชุดคำสั่งภายในระดับ Bare-Metal ที่รันในหน่วยความจำโดยไม่ต้องเรียกโปรแกรมภายนอก:

| คำสั่ง (Builtin) | ไวยากรณ์ (Syntax) | รายละเอียดการทำงาน |
|:---|:---|:---|
| **`alias`** | `alias [name[=val] ...]` | กำหนดหรือแสดงชื่อย่อของคำสั่ง |
| **`builtin`** | `builtin cmd [args...]` | รัน Builtin โดยตรง ข้ามฟังก์ชันชื่อเดียวกัน |
| **`caller`** | `caller [expr]` | แสดงบริบทของ Call Stack ในฟังก์ชัน |
| **`cd`** | `cd [-L\|-P] [dir]` | เปลี่ยนไดเรกทอรีทำงาน |
| **`command`** | `command [-p] [-v\|-V] cmd` | รันคำสั่งโดยข้ามการค้นหาฟังก์ชัน |
| **`declare`** | `declare [-a\|-A\|-i\|-r\|-x] [name=val]` | ประกาศตัวแปรและกำหนดคุณลักษณะ |
| **`dirs`** | `dirs [-c\|-l\|-p\|-v]` | แสดงรายการ Directory Stack |
| **`disown`** | `disown [-h\|-a\|-r] [job...]` | ถอดงานออกจากระบบการจัดการของเชลล์ |
| **`echo`** | `echo [-n\|-e\|-E] [str...]` | พิมพ์ข้อความออกทาง Standard Output |
| **`eval`** | `eval [args...]` | รวมอาร์กิวเมนต์และประมวลผลเป็นคำสั่ง |
| **`exec`** | `exec [-cl] [-a name] [cmd]` | แทนที่โปรเซสของเชลล์ด้วยคำสั่งที่ระบุ |
| **`exit`** | `exit [n]` | ออกจากเชลล์ด้วยรหัสสถานะ `n` |
| **`export`** | `export [-n\|-f\|-p] [name=val]` | ส่งออกตัวแปรไปยัง Child Processes |
| **`fc`** | `fc [-e editor] [-nlr] [first] [last]` | แก้ไขหรือรันคำสั่งจากประวัติซ้ำ |
| **`fg` / `bg`** | `fg [job]` / `bg [job]` | ดึงงานมาทำงานเบื้องหน้า / ส่งไปทำเบื้องหลัง |
| **`help`** | `help [-s] [pattern]` | แสดงคู่มือช่วยเหลือของ Builtin คำสั่งต่างๆ |
| **`history`** | `history [-c\|-d off] [-awrn]` | ดูหรือจัดการประวัติคำสั่ง |
| **`jobs`** | `jobs [-l\|-p\|-n\|-r\|-s]` | แสดงรายการงานที่กำลังรันในเบื้องหลัง |
| **`kill`** | `kill [-s sig\|-n num] pid\|job` | ส่งสัญญาณควบคุมไปยังโปรเซส |
| **`let`** | `let expr [expr...]` | คำนวณนิพจน์คณิตศาสตร์ |
| **`local`** | `local [name=val...]` | ประกาศตัวแปรแบบ Local ภายในฟังก์ชัน |
| **`popd`** | `popd [+N\|-N] [-n]` | ดึงไดเรกทอรีออกจาก Stack |
| **`printf`** | `printf format [args...]` | จัดรูปแบบข้อความตาม Specification |
| **`pushd`** | `pushd [dir\|+N\|-N] [-n]` | ใส่ไดเรกทอรีลงใน Stack |
| **`pwd`** | `pwd [-L\|-P]` | แสดงพาธเต็มของไดเรกทอรีปัจจุบัน |
| **`read`** | `read [-r] [-p prompt] [-t sec] [var]` | อ่านข้อมูลจาก Standard Input |
| **`readonly`** | `readonly [-p] [-a\|-A] [name=val]` | ล็อกตัวแปรหรืออาร์เรย์ไม่ให้แก้ไข |
| **`return`** | `return [n]` | ส่งค่ากลับจากฟังก์ชันเชลล์ |
| **`set`** | `set [-e\|-u\|-x\|-o opt] [--]` | ปรับแต่งพฤติกรรมและการตั้งค่าของเชลล์ |
| **`shift`** | `shift [n]` | เลื่อนตำแหน่งของ Positional Parameters |
